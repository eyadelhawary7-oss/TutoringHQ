Center students · Verified · Draft

Center students, verified

The roster earns its place by answering one question first: who is behind. Everything else is a list of names, which the center already knows. Outstanding sits on the row itself so the answer is visible without opening anything, and tapping a name opens the student, matching the rule used everywhere else a student is listed. The detail screen leads with the balance and keeps method and status on every payment, so a parent's history reads the same way the ledger does. Parent and student are both reachable by call and WhatsApp in one tap. Delivery is set per student: payment links go to exactly one person, because two people holding a link means the same session can be paid twice, while reminders and updates can go to more than one. English and Arabic. Sample data is placeholder.
