## How to keep this document true

Do not edit it by hand. It is generated from the `mgd-num`, `mgd-name` and `mgd-src` markers inside
the merged files. Regenerating it is how you update it. A screen that is not in a merged file does
not exist, and a screen in a merged file cannot be missing from this list.
