CRITICAL Issues (8)

C-01: Arabic-Indic numerals missing across ALL /ar/ pages

Nearly all Arabic pages display Western numerals (0-9) instead of Arabic-Indic (٠-٩). This affects dashboard KPIs, student counts, payment amounts, dates, percentages, and every numeric value. At least 15+ Arabic pages are affected.

Pages: /ar/dashboard, /ar/students, /ar/payments, /ar/groups, /ar/schedule, /ar/attendance, /ar/rooms, /ar/analytics, /ar/benchmarks, /ar/whatsapp-pack, /ar/orders, /ar/settings/billing, /ar/admin — virtually ALL /ar/ data pages
C-02: Admin Renewals tab completely empty

The /en/admin?tab=renewals page renders a completely blank area — no table, no empty state message, no UI at all. Users clicking "Renewals" in admin sidebar see nothing.

Pages: /en/admin?tab=renewals, /ar/admin?tab=renewals
C-03: Admin Withdrawals tab completely empty

The /en/admin?tab=withdrawals page shows no content — no table, no empty state, nothing rendered.

Pages: /en/admin?tab=withdrawals, /ar/admin?tab=withdrawals
C-04: Admin tabs redirect to Overview (Pricing Panel, Platform Config, Vendors, Whatsapp Pack)

Four admin sidebar items silently redirect to the Overview tab instead of loading their own content: Pricing Panel, Platform Config, Vendors, and Whatsapp Pack. Users clicking these see the Overview page again with no indication that the tab failed.

Pages: /en/admin?tab=pricingPanel, /en/admin?tab=platformConfig, /en/admin?tab=vendors, /en/admin?tab=whatsappPack
C-05: English text not translated on Arabic pages

Several Arabic pages contain untranslated English text: "Comprehensive view of your center's performance" on analytics, "Manage Sep–Jun cycles, exam periods, and holidays" on academic, "Camera" / "Bluetooth" / "Manual" on scan page, plan name "Starter" on billing.

Pages: /ar/analytics, /ar/academic, /ar/scan, /ar/settings/billing
C-06: Western date format on Arabic pages

Arabic payment and attendance pages show dates like "12-Apr-2026" using English month abbreviation and Western numerals instead of Arabic-Indic numerals with Arabic month names.

Pages: /ar/payments, /ar/attendance, /ar/orders
C-07: /en/whatsapp and /en/parent-whatsapp both 404/error

Direct URL navigation to /en/whatsapp or /en/parent-whatsapp shows "Something went wrong" error page. The correct URL is /en/whatsapp-pack (sidebar link works), but users who guess or bookmark the intuitive URL will see a crash screen, not a proper 404.

Pages: /en/whatsapp, /en/parent-whatsapp
C-08: /ar/pricing shows error page

The Arabic pricing page (/ar/pricing) returns an error "Something went wrong" instead of showing the pricing plans.

Pages: /ar/pricing

HIGH Issues (12)

H-01: Admin sidebar highlights "Billing" on unrelated pages

When visiting admin sub-pages like /en/admin?tab=staff or ?tab=health, the sidebar incorrectly highlights "Billing" instead of the correct active item.

Pages: Multiple admin tabs
H-02: ?tab=pricing URL param ignored on admin

Navigating directly to /en/admin?tab=pricing shows the Overview tab. The pricing panel requires clicking the sidebar button but doesn't load its own content (see C-04).

Pages: /en/admin?tab=pricing
H-03: Login button says "Submit" instead of "Log in"

The login form's submit button text is "Submit" — should be "Log In" or "Sign In" for standard UX convention.

Pages: /en/login, /ar/login
H-04: Subject names remain in English on Arabic pages

"science" and "math" group labels on students/groups/schedule pages are not translated to Arabic ("علوم", "رياضيات").

Pages: /ar/students, /ar/groups, /ar/schedule
H-05: Scan page UI controls not translated to Arabic

Camera mode labels "Camera", "Bluetooth", "Manual" remain in English on the Arabic scan page.

Pages: /ar/scan
H-06: Admin sub-path URLs cause 404/crash

Admin pages use ?tab= params, but navigating to /en/admin/ceo-dashboard (sub-path style) shows "Something went wrong" error. No redirect or graceful fallback.

Pages: /en/admin/ceo-dashboard and other admin sub-paths
H-07: Landing page pricing shows round numbers vs spec

Pricing section shows 2,000 / 4,500 / 8,000 EGP but the expected values from spec were 1,999 / 4,499 / 7,999 EGP (charm pricing).

Pages: /en/ (landing), /ar/ (landing)
H-08: WhatsApp formula display issue on Arabic page

WhatsApp Pack page in Arabic shows formula as "EGP [f = 12 x ]" with Western numerals in mathematical context instead of proper Arabic formatting.

Pages: /ar/whatsapp-pack
H-09: "Export CSV" and "Export PDF" buttons not translated

Action buttons like "CSV" and "Export PDF" remain in English on Arabic pages.

Pages: /ar/attendance, /ar/analytics
H-10: Error page missing sidebar and navigation

The "Something went wrong" error page shows only a "Try again" button with no sidebar, no wordmark, no navigation — user has no way back to the app except browser back button.

Pages: All error pages (e.g., /en/whatsapp)
H-11: 4 admin centers missing sales team assignments

Center Assignments page shows a warning: "4 centers missing assignments." These need to be assigned before launch.

Pages: /en/admin (Center Assignments)
H-12: Platform Health shows "Paymob: SANDBOX"

The Platform Health page shows Paymob integration in SANDBOX mode. This must be switched to LIVE before launch.

Pages: /en/admin (Platform Health)

LOW Issues (9)

L-01: "Whatsapp Pack" should be "WhatsApp Pack"

The admin sidebar and Settings page link both read "Whatsapp Pack" with lowercase 'a' — proper brand name is "WhatsApp" (capital A).

Pages: /en/admin sidebar, /en/settings
L-02: "Forgot Pin" should be "Forgot PIN?"

Login page shows "Forgot Pin" — "PIN" is an acronym and should be fully capitalized, plus add question mark.

Pages: /en/login
L-03: "No Account" should be "Don't have an account?"

Login page shows "No Account" which is grammatically incomplete. Should be "Don't have an account?" or similar.

Pages: /en/login
L-04: "1 cards" grammar error on Orders page

Order entries display "1 cards" — should be "1 card" (singular when count is 1).

Pages: /en/orders
L-05: Redundant "Benchmarks" subtitle

The Benchmarks page shows heading "Benchmarks" with subtitle "Benchmarks" — duplicate text.

Pages: /en/benchmarks
L-06: Sidebar label mismatch — "Parent WhatsApp" vs URL /whatsapp-pack

Sidebar says "Parent WhatsApp" but the URL is /en/whatsapp-pack, and Settings shows "WhatsApp Pack". Naming should be consistent across all locations.

Pages: Sidebar, Settings, URL
L-07: Date format "12-Apr-2026" inconsistent with rest of app

Some dates use "12-Apr-2026" format while others use "Apr 02, 2026" or "May 23, 2026". Should standardize on one format.

Pages: /en/payments, /en/attendance
L-08: Card order IDs are hex codes, not user-friendly

Order IDs like "#7878DE77" and "#202DE5B1" are raw hex — consider more readable IDs (e.g., ORD-0001).

Pages: /en/orders
L-09: Admin sidebar item "Card Orders" — column header says "admin.orderId"

The Card Orders table has a column header showing the raw i18n key "admin.orderId" instead of the translated label.

Pages: /en/admin?tab=cardOrders

Pre-Launch Recommendations (Priority Order)

🚨 LAUNCH BLOCKERS (must fix before go-live):
  1. Implement Arabic-Indic numeral formatting — Create a global utility that converts all displayed numbers to ٠١٢٣٤٥٦٧٨٩ on /ar/ routes. This is the #1 blocker affecting 15+ pages.
  2. Fix Admin Renewals & Withdrawals tabs — Add content or proper empty state messages.
  3. Fix /ar/pricing error page — Arabic pricing page crashes.
  4. Switch Paymob from SANDBOX to LIVE — Cannot accept real payments in sandbox mode.
  5. Wire up 4 admin tabs (Pricing Panel, Platform Config, Vendors, Whatsapp Pack) — Currently redirect to Overview silently.
  6. Translate remaining English text on Arabic pages — Analytics subtitle, Academic subtitle, Scan controls, date formats.
⚠️ SHOULD FIX (high impact, moderate effort):
  1. Fix admin sidebar highlighting (wrong item highlighted on some tabs)
  2. Change login button from "Submit" to "Log In"
  3. Add navigation to error boundary page (sidebar + "Back to Dashboard")
  4. Translate group/subject names on Arabic pages
  5. Standardize date formats across the app
  6. Assign 4 unassigned centers to sales team members
